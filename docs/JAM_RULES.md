## Theme

The theme is SHIFT, and its interpretation is entirely up to the entrant. The
jam page lists examples such as shifting gears, perspectives, dimensions, bits,
night shifts, or using only the Shift keys as controls.

## What must be submitted

Both are required:

1. A **public GitHub repository** containing the source code; its URL is
   entered at submission.
2. A **playable game** submitted through the Game Off 2026 page on itch.io.

Pushing to GitHub alone does not enter the game.

- Unfinished prototypes may be submitted.
- Updates are allowed during the submission period.
- Once voting starts, avoid changes except critical bug fixes, and note what changed.

## Rules

| Topic | Rule |
|---|---|
| Team size | No maximum. Solo entries welcome. Teams can form after the jam starts; multiple submissions are allowed. |
| Eligibility | Anyone who joins the jam. No age/location restrictions were found on the pages read. |
| Tech | Any programming language, engine, or library. |
| Platforms | All platforms welcome; no browser requirement. Clear instructions for playing are required. |
| Licence | Any licence. Open source is encouraged but not required. Code and assets may be licensed separately. |
| Pre-existing work | Templates, starter projects, libraries and reusable code are fine, but the vast majority of the work must be done during the jam. Do not submit an old game with minor changes. |
| Third-party assets | Attribution is required where the asset's licence requires it. Paid/proprietary assets whose licence forbids redistribution may be left out of the repo; use placeholders and explain in the README what is missing. |
| Content | No strict rules beyond itch.io's platform rules. Mature content should be labelled; adult or very graphic games are less likely to be featured by GitHub. |
| Prizes | No physical or cash prizes. Winners are featured on the GitHub Blog and social channels. |

## AI use

- AI tools are **allowed** for coding, brainstorming, images, audio and other assets.
- **Disclosure is required**: the submission form asks about AI use.
- Using AI does not disqualify a game or automatically affect its score.

For this project: the source is public but all rights reserved (`LICENSE`),
which the jam's "any licence" rule allows. Code is written with AI assistance (Claude Code); art is
public domain or generated by code effects. See `CREDITS.md`, and disclose
this accurately on the submission form.

## Voting

- Participants with a qualifying submission (and their teammates) rate entries
  after submissions close. Non-submitters cannot vote.
- Rating other games is encouraged but not required for your game to be rated.
- Categories: **Overall, Gameplay, Graphics, Audio, Innovation, Theme interpretation**.

## Submission checklist

- [ ] Repository is public on GitHub and pushed before the deadline
- [ ] Game submitted on the itch.io jam page, with the repo URL
- [ ] Play instructions and controls in the README and on the itch.io page
- [ ] AI-use disclosure filled in on the submission form
- [ ] `CREDITS.md` lists every third-party asset with source and licence
- [ ] Mature content labelled, if any
- [ ] No secrets, signing keys or personal data in the repo or its history
